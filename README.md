**Description**

The goal of our project is to create a multifunctional application based on the Alias word guessing game. 
The functionality of this application includes the ability to create teams and change their names. Next is the word guessing game itself, where it is possible to skip a word or press the "Next" button to count as a guessed word. After the round, which lasts 60 seconds, the mid results are displayed, with the number of words, as well as guessed and not guessed. At the end of the game, the final score and ranking are calculated.
